# 17.0 Upgrade Guide

[Release notes](https://github.com/LuckyPennySoftware/AutoMapper/releases/tag/v17.0.0).

## AutoMapper now targets .NET 10, .NET 11, .NET Standard 2.0 and .NET Framework 4.7.1

The `net8.0` and `net9.0` builds have been removed, because both versions of .NET reach end of support in November 2026.

Apps on .NET 8 or .NET 9 can still install this package, and they get the `netstandard2.0` build. We recommend moving to .NET 10 or later. The `netstandard2.0` build doesn't include the default interface implementations from the framework-specific builds, so code that implements `AutoMapper.Execution.IValueResolver` or `AutoMapper.Configuration.IPropertyMapConfiguration` may need to change. See [API Changes](API-Changes.md).

## Supported versions

Security fixes are provided for the current and previous major versions. With this release, those are 17.x and 16.x, and 15.x is no longer supported.
